# Grilling

Interview the user relentlessly about every aspect of the plan until you reach a shared
understanding. Walk down each branch of the decision tree, resolving dependencies between decisions
one by one. For each question, give your recommended answer.

Ask the questions one at a time and wait for the answer before continuing. Asking several questions
at once is bewildering.

If a *fact* can be found by exploring the environment — the filesystem, the repository, the tools —
look it up rather than asking. The *decisions* belong to the user: put each one to them and wait.

Do not act on the plan until the user confirms that you have reached a shared understanding.
